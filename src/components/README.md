# src/components — FRONTEND

Presentation only. No data access, no business rules, no `@/server` imports.

| Folder | Contents |
|---|---|
| `ui/` | shadcn/ui primitives. Generated by the CLI, owned by us, edited rarely. Button, input, table, dialog, select, etc. |
| `layout/` | The app shell: sidebar, top bar, breadcrumbs, page header, branch/period switchers. |
| `shared/` | Cross-module app components built from `ui/`: data table, money cell, status badge, date range picker, empty state, confirm dialog, voucher line editor. |

Feature-specific components live in `src/features/<module>/`, not here. A component
belongs in `shared/` only once a second module needs it.

## Rules

1. Server Components by default. Add `"use client"` only on the leaf that actually
   needs interactivity — a table row with a dropdown, not the whole page.
2. Components receive data as props. They never fetch it themselves.
3. Money arrives as a **string** already formatted by the server, or as a string
   amount plus a currency code. Never `Decimal`, never `number`.
4. No component imports from `@/server/**`. If a component needs data, the page
   fetches it and passes it down.
